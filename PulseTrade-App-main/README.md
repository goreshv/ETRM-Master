# PulseTrade App

ETRM Master React Native application for energy trading and risk management.

## Features

- Real-time trading simulator
- Learning modules
- Quiz system
- Roadmap tracking

## Getting Started

1. Install dependencies: `npm install`
2. Start Expo: `npm start`
3. Scan QR code with Expo Go app
